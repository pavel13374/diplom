# Sentinel — визуальный язык

Продукт — специализированный инструмент дежурной смены, а не витрина.
Отсюда все решения ниже.

## 1. Принципы

1. **Один сигнал на одно значение.** Уровень инцидента несёт кромка строки
   и цвет слова — не заливка, не рамка, не иконка одновременно.
2. **Иерархия делается типографикой,** а не рамками: вес, кегль, регистр,
   позиция, отступ. Рамка остаётся только у того, что можно нажать.
3. **Цвет семантичен.** Нейтральный интерфейс; яркий цвет означает уровень,
   кампанию, нарушенный срок или выбранное состояние — и ничего больше.
4. **Плотность важнее воздуха.** Строка списка — строка, а не карточка.

## 2. Токены

Цвет, шкала кегля, отступы, радиусы, длительности — в первых двух секциях
`design-system.css`. Значения в разметку не попадают: тест
`tests/test_design_system.py` это проверяет.

- Кегль: 10 / 11 / 12 / 13 / 14 / 18 / 24 / 28 / 36.
- Начертания: 400, 500, 600.
- Радиусы: 6 (панель), 4 (контрол), 2 (мелкие образцы), 999, 50%, 0.
- Шрифты: Inter (интерфейс), JetBrains Mono (идентификаторы, пути, техники).

## 3. Поверхности

`--bg` → `--surface-1` (панель) → `--surface-3` (наведение) →
`--surface-4` (выбор). Панель отличается от полотна сдвигом фона и
волосяной линией сверху; рамок и теней у панелей нет.

Заголовок панели — строка 32px: прописные 10px, трекинг `--ls-label`,
цвет `--text-3`, снизу волосяная линия.

## 4. Строка списка

```
▌ Первичная формулировка — что произошло            2ч
  HIGH · @actor · кампания · 4 алерта · 0.99         TP  НОВЫЙ
```

- кромка слева (3px) — уровень; `low` получает нейтральную линию;
- первая строка — суть события, `--text-1`, 14px/500;
- вторая — метаданные 11px `--text-3`, разделитель «·»;
- правая колонка — время в очереди и статус/вердикт;
- `.sla.breach` — единственное состояние, которое повышает голос.

## 5. Статусы

| значение   | подача                                          |
|------------|-------------------------------------------------|
| severity   | кромка строки + слово прописными в цвете уровня |
| кампания   | слово в `--campaign` внутри метаданных          |
| TP / FP    | прописные; TP подчёркнут критическим цветом     |
| статус     | прописные, приглушённые                          |
| SLA        | число моноцифрами; цвет только при нарушении     |

Заливок и обводок у этих значений нет.

## 6. Верхняя панель

Порядок веса: название раздела (18px/600) → поиск (подчёркнутое поле) →
системная строка (подпись прописными + значение, волосяные разделители) →
язык и тема (кнопки без рамок).

При сужении экрана системная строка теряет пункты справа налево.

## 7. Данные

Библиотека — `static/charts.js`: `dsDonut`, `dsArea`, `dsBars`, `dsSpark`.
Палитра `--chart-1…5` выведена из основной: сиреневый, мятный, тёплый,
стальной, коралловый; проверена на дефициты цветовосприятия.

Кольцо отвечает на один вопрос и держит ответ числом в центре.
Полосы сравниваются по длине, имена читаются в столбец.

## 8. Движение

`--dur-fast` 120ms / `--dur` 180ms / `--dur-slow` 260ms,
`cubic-bezier(.23,1,.32,1)`. Анимируются только `transform` и `opacity`
(кроме отрисовки дуг). На `:hover` подъёмов и масштабирования нет.
`prefers-reduced-motion` отключает всё.

## 9. Проверки

- `tests/test_design_system.py` — границы системы;
- `tests/test_contrast.py` — WCAG 2.1 AA для обеих тем;
- `tests/test_page_scripts.py` — страницы доходят до опроса данных;
- `tests/test_i18n_rules.py` — словарь синхронен с правилами.
